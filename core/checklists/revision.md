# Revisión humana de cambios

- [ ] Se entiende el requisito y el comportamiento antes/después.
- [ ] No se dieron por contestadas preguntas abiertas ni se añadieron extras.
- [ ] Controladores solo adaptan HTTP; dependencias y composición respetan arquitectura.
- [ ] Se probaron errores, permisos cruzados y concurrencia cuando afectan la regla.
- [ ] Dinero exacto, zonas horarias, claves y auditoría tienen tratamiento revisado.
- [ ] Pruebas ejecutadas concuerdan con afirmaciones y no se ocultaron fallos.
- [ ] El alumno explica el código sin IA y decide aceptar/cambiar/rechazar.

Registrar fecha, responsable real, decisión y evidencia en la bitácora. No completar esos datos en nombre del alumno.
