# Añadir pruebas de una regla

Lee AGENTS.md, contexto y arquitectura del proyecto.

Entradas que debe aportar o localizar el alumno: RN/RF/CA, fuente y comportamiento confirmado.

Propón pruebas de frontera, negativas y aislamiento. Usa reloj/criterios explícitos para lógica pura y BD de pruebas para persistencia. Ejecuta comandos existentes y reporta fallos; no crear pruebas que solo repiten implementación ni fabricar cobertura.

Entrega un resultado pequeño, trazable y explicable. No inventes respuestas ni comandos. Aplica core/checklists/terminado.md y registra evidencia real. Si falta información, avanza solo lo independiente y enumera el bloqueo exacto.
